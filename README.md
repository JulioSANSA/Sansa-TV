# Inicio Julio

Pantalla de inicio estilo Apple TV para Samsung Tizen, como módulo de TizenBrew.

Apps (en orden): Movistar Plus+, HBO Max, Crunchyroll, Netflix, Disney+, Prime Video, YouTube.

## Instalar
1. Sube esta carpeta a un repo público de GitHub (`JulioSANSA/Sansa-TV`).
2. En la tele, abre TizenBrew → Module Manager (botón verde) → Add module → GitHub → `JulioSANSA/Sansa-TV`.
3. Abre "Inicio Julio" desde TizenBrew.

Mando: ← → para moverte, OK para abrir, Atrás para salir.
